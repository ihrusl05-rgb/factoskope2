# ChangeLog

## Версия 0.1.5 / 07.10.2026

- Страницы импорта объединены в `/admin/content/import/` с выбором типа данных и отдельного Excel-файла.
- Гороскопы из общей страницы сохраняются черновиками; факты и гороскопы показывают одинаковый отчёт и ошибки строк.
- Создание отчёта вынесено в `build_import_report`; признак завершения обработки называется `import_completed`.
- API гороскопов получает тексты всех знаков одним запросом к базе.
- Существующие UI-тесты обновлены под общий маршрут и сохранение гороскопов.

## Версия 0.1.4 / 07.10.2026

- Общее чтение Excel, проверка заголовков и сбор строк вынесены в `read_excel_rows`.
- Парсеры фактов и гороскопов используют общий механизм чтения с сохранением номеров строк в ошибках.
- Проверка расширения и размера файла вынесена в `ExcelImportForm`; формы фактов и гороскопов наследуют общие правила.
- В README описаны порядок обработки Excel и наследование форм.

## Версия 0.1.3 / 07.10.2026

- Подключён отдельный импорт фактов через админку: кнопка, форма, сохранение корректных строк и отчёт об ошибках.

- Восстановлен вывод ошибок строк и предпросмотра гороскопов на странице проверки Excel.

- Добавлено сохранение корректных фактов из Excel; повторный импорт обновляет категорию по совпадению текста и возвращает отчёт с ошибками строк.

- Добавлен парсер отдельного Excel-файла с фактами: обязательная колонка `Текст`, необязательная `Категория`.
- Пустой текст и категория длиннее 64 символов возвращаются в отчёте об ошибках строк.
- Нормализация фактов вынесена в отдельную функцию; поле `ordering` из файла не читается.

## Версия 0.1.2 / 07.10.2026

- На главной странице админки и в списке гороскопов добавлена кнопка «Загрузить Excel».
- После проверки файла на сайте отображаются количества правильных и ошибочных строк, причины ошибок и предпросмотр гороскопов.
- Ошибки чтения файла и обязательных колонок выводятся у поля загрузки.
- Страница проверки сохраняет навигацию админки; данные пока не записываются в базу.

## Версия 0.1.1 / 06.10.2026

- Корректные строки Excel сохраняются черновиками; ошибки отдельных строк возвращаются в отчёте.
- Повторный импорт обновляет гороскопы по знаку и дате без создания дубликатов.
- Отчёт содержит количество созданных и обновлённых записей, номера ошибочных строк и причины.
- `parse_horoscop()` возвращает два списка: подготовленные гороскопы и ошибки.
- Импорт использует колонки `Дата`, `Знак` и `Текст`; ошибки файла и заголовков останавливают импорт до записи в базу.

## Версия 0.1.0 / 05.10.2026

- Добавлено чтение Excel-файлов с колонками `Дата`, `Знак` и `Гороскоп`.
- Даты приводятся к типу `datetime.date`.
- Русские и английские названия знаков приводятся к кодам модели.
- Добавлена проверка обязательных полей и содержимого строк.
- Ошибки импорта содержат номер проблемной строки Excel.
- Для функций сервиса добавлены Google-style docstrings.

## Версия 0.0.1 / 02.10.2026

- Создан базовый Django-проект.
- Добавлены модели фактов и гороскопов.
- Добавлены API фактов и гороскопов.
- Подключена административная панель.
