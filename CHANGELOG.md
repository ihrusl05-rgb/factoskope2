# ChangeLog

## Версия 0.1.0 / 05.10.2026

- Добавлено чтение Excel-файлов с колонками `Дата`, `Знак` и `Гороскоп`.
- Даты приводятся к типу `datetime.date`.
- Русские и английские названия знаков приводятся к кодам модели.
- Добавлена проверка обязательных полей и содержимого строк.
- Ошибки импорта содержат номер проблемной строки Excel.
- Для функций сервиса добавлены Google-style docstrings.

## Версия 0.0.1 / 02.10.2026

- Создан базовый Django-проект.
- Добавлены модели фактов и гороскопов.
- Добавлены API фактов и гороскопов.
- Подключена административная панель.
